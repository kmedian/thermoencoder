# Security Policy

## Supported Versions

Only the latest release of thermoencoder receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report them by emailing the maintainer directly:
**554c46@gmail.com**

Include as much detail as possible:
- A description of the vulnerability
- Steps to reproduce or a proof-of-concept
- The potential impact

You can expect an acknowledgement within 5 business days and a resolution or mitigation plan within 30 days.
